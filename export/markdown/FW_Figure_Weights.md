# Figure Weights (FW)

- **Domain:** Fluid Reasoning
- **URL:** https://cognitivemetrics.com/test/CORE/FW
- **Time limit:** 45 seconds per question

## Instructions

This subtest contains 30 questions and assesses fluid reasoning using novel puzzles.
Each question will be timed 45 seconds per item. Work carefully.
No external aids (calculator, notes, scratch paper, etc.) are allowed. All work must be done mentally.
You may attempt some sample items on the next page before the test begins.
