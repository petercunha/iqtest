# Digit Span (DS)

- **Domain:** Working Memory
- **URL:** https://cognitivemetrics.com/test/CORE/DS
- **Time limit:** None seconds per question
- **Items:** n/a

## Instructions

This test is spoken aloud , so we strongly recommend using headphones and being in a quiet environment. Please ensure you have a stable internet connection.
The instructions will be spoken to you once you start the test.
Digits are randomized to prevent practice effects.
This test is normed by age, so please enter an accurate age.
No external aids (notes, scratch paper, etc.) are allowed. Everything should be done mentally.

> Spoken aloud (audio-administered). Skipped per requirements. Digits are randomized at runtime: 3 subtests (Forwards, Backwards, Sequencing), 8 items each (2-9 digits, two trials per item), 60s response window.
