# Visual Puzzles (VP)

- **Domain:** Visual Spatial
- **URL:** https://cognitivemetrics.com/test/CORE/VP
- **Time limit:** 45 seconds per question
- **Items:** 26

## Instructions

This subtest contains 27 questions and assesses spatial reasoning using visual-based tasks.
Each question will be timed 45 seconds. Work quickly and carefully.
No external aids (notes, scratch paper, drawing tools, etc.) are allowed.
Make sure you follow these rules:
Your objective is to select exactly 3 options to reconstruct the given puzzle.
The selected pieces may be rotated, but they may not be flipped, altered in any other way, or overlap.
